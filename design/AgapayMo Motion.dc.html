:root {
  --dur-press: 90ms;  --dur-quick: 160ms;  --dur-base: 200ms;
  --dur-slow: 400ms;  --dur-draw: 600ms;   --dur-loop: 1400ms;

  --ease-out: cubic-bezier(0.2, 0.8, 0.2, 1);
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
}
@media (prefers-reduced-motion: reduce) { :root { --stagger: 0ms; } }
base.css: the reduced-motion fix (delays as well as durations)
@media (prefers-reduced-motion: reduce) {
  *:not(.motion-safe), *:not(.motion-safe)::before, *:not(.motion-safe)::after {
    animation-delay: 0s !important;
    transition-delay: 0s !important;
  }
}
Trigger pattern
// when the real event fires (saved, received, read, approved):
el.dataset.just = 'land';
el.addEventListener('animationend', () => delete el.dataset.just, { once: true });
/* keyframes only play the way in: the resting CSS is the final state */
[data-just="land"] { animation: land var(--dur-base) var(--ease-out) backwards; }

  1. Only real events move: a tap that landed, data that arrived, work that is running, a drawing made from real output. Nothing on load, scroll or hover; nothing loops unless work runs; rows never enter one by one.
  2. Only transform, opacity, clip-path and stroke-dashoffset. Meters use scaleX.
  3. The resting CSS is the final state. data-just on the real event, removed on animationend. No JS animation loops, no new rAF loops, no libraries.
  4. Never delay input or results. No fake “Verifying…”. Stagger only real output sets, within --dur-draw.
  5. Never animate a clinical result. 6a, 6b, 7a appear at once; 6a turns into 6b instantly. Only 6c's saved check may stamp. During the 60 s count only the timer, fill bar and trace move.
  6. Text twin: every motion that reports news has its words in role="status".
  7. Flashing: never more than 3 a second.
  8. One region at a time; a screen's arrival ends within --dur-draw. Exits instant. Page changes are hard cuts.
  9. Banned: confetti, fake progress, invented waits, scanning-line sweeps, “AI thinking” when nothing runs, sound.
  10. Haptics (P1): navigator.vibrate(15), feature-detected, on save, confirm, start the watch, flag, receive. Never during Hinga. Never the only signal.
