Agapay design system

A field tool for barangay health workers in the days after a typhoon. Readable in direct sun, usable with one hand, calm when there is no signal. Light mode only for this build.

  1. 1. Ink for actions, color for meaning.

    Buttons are ink. Green, amber, red and lagoon only ever mean a status, so color is never decoration.

  2. 2. Every status is color + icon + word.

    Nothing depends on color alone, so it reads for color-blind users and on a dim, scratched screen.

  3. 3. Built for sun and thumbs.

    18 px body text, 48 px minimum targets, the main action in the bottom third, every text pair 4.5:1 or better.

Color

Warm paper and brown-black ink, so the app feels like a field notebook, not a hospital. Four status hues sit far apart on the wheel (green 150°, amber 70°, red 27°, lagoon 222°). Values were set in OKLCH, then checked as sRGB hex.

Type

One family, two cuts. Both are free to self-host under the SIL Open Font License 1.1.

Aa Il1 O0
Atkinson Hyperlegible Next

All UI text. Braille Institute of America, SIL OFL 1.1. Weights used: 400, 500, 600, 700, 800. Letterforms are drawn to stay apart (I, l, 1; O, 0) for low-vision readers, which also helps in glare. Covers ñ for Santo Niño.

DEMO-LOT-24A
Atkinson Hyperlegible Mono

Lot numbers, export codes, MB figures, timers. Braille Institute of America, SIL OFL 1.1. Weights used: 500, 700. 0 and O, 1 and l never look alike: the same mix-ups the box reader has to catch.

Components

Shown at phone size (335 px content width inside a 375 px screen). Cards are used sparingly: rows on paper are the default.

Buttons

Pressed: primary goes to #000 and moves down 1 px. Laptop hover: primary #3A332C, secondary fills --sunken. Destructive solid only inside a confirm sheet.

Text field and select

Labels always above, never placeholders. Select opens the phone's native picker. The box-reader's “Sure / Please check” field states are in Components 2 below.

Local-AI indicators

One quiet line, no pill and no border: lagoon for the device, ink-2 for Offline. Under the title on main screens, top right in flows. Tap opens its sheet (Local AI states L5b, L7). Online: only the device part shows. Offline is never red.

Bottom nav

Components 2: AI result review

What the phone read is always editable, and its confidence shows as a look, not a percentage. “Please check” is set when a field's confidence is below the box reader's CHECK_BELOW threshold, or the field wasn't found.
